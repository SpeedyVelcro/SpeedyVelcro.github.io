Just released a small patch for the

<!--more-->

![Screenshot of the Game Jolt login menu from Squid Savings](/assets/images/blog/2026-11-03-squid-savings-1.2.1)

## Change Notes
This hotfix restores the Game Jolt login menu, which was accidentally
removed from Game Jolt builds in v1.2.0 due to a bug. Because it only
impacts Game Jolt, this hotfix will not be published on Newgrounds or
itch.io.

### Bug Fixes
- Restores missing Game Jolt login menu, making it possible to unlock
  trophies on Game Jolt again.
